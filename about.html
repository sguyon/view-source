About this site

View source

This is the 2026 reboot of my personal site. It started when I found an old fork of htmleditor sitting in my GitHub — a page that shows its own source and lets you edit it live. That trick always fascinated me, so I rebuilt the site around it. Every page here is editable: press / to open the code, tweak it, watch it update. The editor also has an AI prompt built in, because hey it's 2026 — who really types code anymore.

I learned a lot of what I know by reading other people's code. When I started using the web I spent as much time hitting "view source" as browsing — then came open source, Linux, Ruby on Rails...

Every single web page you visited contained the code showing you how it was created. The entire internet became a library of how-to guides on programming.

— Clive Thompson, Coders (via Jim Nielsen)

Playing with code

The animations come from my fascination with creative coding. Demos, Processing, John Maeda, Flash-era websites, and FWA: I'd spend hours playing with code just for the pleasure of building something satisfying to watch move.

Then came information design, data visualization, Bret Victor's explorable explanations — code that could teach, tell stories, and help people create. That got me into analytics, observability and the broader dev tools space.
